1. Aim
To demonstrate the use of delegates, callbacks, and synchronous and asynchronous method invocation in C#.

4. Program
Copy this code into Program.cs. It follows the lab manual's delegate and callback example.

using System;
using System.Threading;

class Program
{
    // Define a delegate type
    public delegate void ProcessDelegate(int number);

    static void Main(string[] args)
    {
        // Synchronous delegate invocation
        Console.WriteLine("Synchronous Delegate Invocation:");
        ProcessDelegate processDelegate =
            new ProcessDelegate(ProcessNumber);
        processDelegate(10);

        // Using delegate as a callback
        Console.WriteLine("\nUsing Delegate as a Callback:");
        ExecuteWithCallback(20, ProcessNumber);

        // Asynchronous delegate invocation
        Console.WriteLine("\nAsynchronous Delegate Invocation:");
        ProcessDelegate asyncProcessDelegate =
            new ProcessDelegate(ProcessNumber);

        IAsyncResult asyncResult =
            asyncProcessDelegate.BeginInvoke(30, null, null);

        // Do other work in the main thread
        Console.WriteLine("Doing other work in the main thread...");

        // Wait for asynchronous operation to complete
        asyncProcessDelegate.EndInvoke(asyncResult);

        Console.WriteLine("\nProgram has finished execution.");
    }

    // Method matching the delegate signature
    public static void ProcessNumber(int number)
    {
        Console.WriteLine($"Processing number: {number}");
        Thread.Sleep(2000);
        Console.WriteLine($"Finished processing number: {number}");
    }

    // Method that accepts a callback delegate
    public static void ExecuteWithCallback(
        int number, ProcessDelegate callback)
    {
        Console.WriteLine("Starting execution...");
        callback(number);
        Console.WriteLine("Finished execution.");
    }
}



Important for your lab: This exact program uses BeginInvoke() and EndInvoke(), which work with delegates in .NET Framework but are not supported in modern .NET (such as .NET 6, 8, or 10). If you encounter a compilation error, create a .NET Framework Console App to run the manual's program as written.
5. Explanation
Concept	Explanation
Delegate	A type-safe reference to a method with a matching signature.
ProcessDelegate	Defines a delegate that accepts an integer and returns nothing (void).
Synchronous invocation	processDelegate(10) executes the method and waits for it to finish.
Callback	A method (ExecuteWithCallback) receives another method through a delegate and invokes it.
Asynchronous invocation	BeginInvoke() starts the delegate operation without immediately waiting for completion.
EndInvoke()	Waits for the asynchronous operation to finish and completes the invocation.
Thread.Sleep(2000)	Pauses the executing thread for approximately two seconds.
How the program works
1. The delegate is declared with an integer parameter.
2. ProcessNumber(10) is invoked synchronously.
3. ExecuteWithCallback(20, ProcessNumber) demonstrates passing a method as a callback.
4. The delegate is invoked asynchronously with the value 30.
5. The main thread prints a message while the asynchronous operation is running.
6. EndInvoke() waits for the operation to complete before the program exits.

8. Viva questions
1. What is a delegate?
A delegate is a type-safe reference to a method.
2. What is a callback?
A callback is a method passed to another method so that it can be invoked when required.
3. What is the difference between synchronous and asynchronous execution?
- Synchronous: The caller waits for the operation to finish.
- Asynchronous: The caller can continue other work while the operation executes.
4. What is Thread.Sleep(2000)?
It pauses the current thread for approximately 2,000 milliseconds, or two seconds.
5. Why do we use EndInvoke()?
To wait for the asynchronous delegate operation to finish and retrieve its completion result.
