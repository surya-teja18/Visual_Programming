Task 7: Sending Mail Using SMTP in ASP.NET
Visual Programming Lab Manual · Pages 28–29
I'll follow your lab manual and provide a Notepad-ready reference with the procedure, ASP.NET Web Form code, C# code-behind, explanation, and expected output.
1. Aim
To develop a simple ASP.NET Web Form that demonstrates sending emails using SMTP in the .NET Framework.
2. Software requirements
- Microsoft Visual Studio
- ASP.NET Web Forms
- C# and .NET Framework
- SMTP server configuration and valid email credentials
3. Procedure / steps
1. Open Microsoft Visual Studio.
2. Create a new ASP.NET Web Application (.NET Framework) project.
3. Name the project ToDoPlanner.
4. Select Web Forms as the project template.
5. Add a Web Form named SendMail.aspx.
6. Design the form with fields for recipient email, subject, and message body.
7. Add a button to send the email and a label to display the status.
8. Open SendMail.aspx.cs and add the C# SMTP logic.
9. Configure the SMTP server and valid credentials in the application configuration.
10. Run the application, fill in the fields, and click Send Mail.

5. C# code-behind — SendMail.aspx.cs
Open SendMail.aspx.cs and paste the following code.

using System;
using System.Net;
using System.Net.Mail;

namespace ToDoPlanner
{
    public partial class SendMail : System.Web.UI.Page
    {
        protected void btnSend_Click(object sender, EventArgs e)
        {
            try
            {
                MailMessage mail = new MailMessage();

                mail.From = new MailAddress("your-email@example.com");
                mail.To.Add(txtTo.Text);
                mail.Subject = txtSubject.Text;
                mail.Body = txtBody.Text;

                SmtpClient smtp = new SmtpClient();

                smtp.Host = "smtp.yourserver.com";
                smtp.Port = 587;
                smtp.Credentials =
                    new NetworkCredential("username", "password");

                smtp.EnableSsl = true;
                smtp.Send(mail);

                lblStatus.Text = "Email sent successfully!";
            }
            catch (Exception ex)
            {
                lblStatus.Text = "Error: " + ex.Message;
            }
        }
    }
}



Important: The SMTP host, sender address, username, and password above are placeholders. Replace them with valid SMTP settings before attempting to send an actual email. Use an authorized SMTP account and do not store real passwords in source code.
6. Explanation
Code	Purpose
MailMessage	Creates the email message.
mail.From	Specifies the sender's email address.
mail.To.Add()	Specifies the recipient.
mail.Subject	Sets the email subject.
mail.Body	Sets the email message.
SmtpClient	Connects to an SMTP server to send the email.
smtp.Host	Specifies the SMTP server address.
smtp.Port	Specifies the SMTP port; 587 is commonly used with STARTTLS.
smtp.EnableSsl = true	Enables TLS/SSL support for the SMTP connection.
smtp.Send(mail)	Sends the email.
try-catch	Handles errors and displays the error message.
